# Визуализатор алгоритма Дейкстры

Программа предназначена для наглядной демонстрации работы алгоритма Дейкстры при поиске кратчайшего пути во взвешенном неориентированном графе. Приложение позволяет вручную создавать вершины и рёбра, задавать веса, выбирать начальную и конечную вершины, а затем пошагово наблюдать, как алгоритм обрабатывает граф.

## Возможности

- добавление вершин кликом по холсту или по заданным координатам;
- создание рёбер между вершинами с указанием положительного веса;
- выбор стартовой и конечной вершины;
- генерация случайного связного графа с настраиваемыми параметрами;
- пошаговая анимация работы алгоритма Дейкстры;
- мгновенный вывод найденного кратчайшего пути;
- подсветка текущей вершины, посещённых вершин и итогового маршрута.

## Как запустить

Для запуска нужен Python 3 с установленной стандартной библиотекой `tkinter`.

```bash
python dijkstra_visualizer.py
```

После запуска откроется окно приложения. Слева находится панель управления, справа — рабочее поле для построения и просмотра графа.

## Основные режимы

- **Добавить вершину** — клик по холсту создаёт новую вершину.
- **Выбрать старт** — клик по существующей вершине назначает её начальной.
- **Выбрать финиш** — клик по существующей вершине назначает её конечной.
- **Добавить ребро** — нужно последовательно выбрать две вершины и ввести вес ребра.

Кнопка **Запустить алгоритм** показывает работу Дейкстры с анимацией, а **Показать результат** сразу отображает кратчайший путь и его длину.
